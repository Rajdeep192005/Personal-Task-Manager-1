#  SparkTask Pro - Personal Task Manager

A beautiful and responsive task management application built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies - just clean, fast, and efficient code.

 Live Demo

**🔗 Live Application:** [https://personal-task-manager-1.vercel.app/]  


~ Features

**Modern Design**
- Beautiful gradient UI with glass morphism effects
- Smooth animations and transitions
- Fully responsive (works perfectly on mobile & desktop)
- Custom fonts and elegant typography

 **Core Functionality**
-  Add new tasks with descriptions
-  Set priority levels (High, Medium, Low)
-  Add due dates with date picker
-  Edit existing tasks
-  Delete tasks with confirmation
-  Mark tasks as complete/incomplete

 **Smart Organization**
- **Filter tasks by**: All, Pending, Completed, High Priority, Due Today
- Real-time search and filtering
- Progress tracking with visual progress bar
- Task statistics dashboard

 **User Experience**
- Secure login system with demo credentials
- Guest mode for quick access
- User-specific task storage
- Persistent data using localStorage
- Beautiful notifications and alerts

 **Productivity Insights**
- Progress percentage tracking
- Task completion statistics
- Priority-based task counts
- Visual progress indicaton.
